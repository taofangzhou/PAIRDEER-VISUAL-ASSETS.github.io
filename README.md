# 双鹿电池 · 网销视觉资料中心

这是资料工具，不是交易商城。原有品牌 Logo、3 张轮播海报、53 款产品的主图和完整详情图均来自用户提供的发布包。

## 已实现

- 白色/酒红品牌首页，PC 与手机响应式布局；所有窗口共用一个资料 API。
- 关键词搜索、34 个省级地区及所附城市名单、8 个线上渠道筛选。
- 三张轮播及图片格式、主图/详情/SKU、设计提需说明。
- 产品详情、最多 9 张主图、触摸切换、连续长图、参数和视频、单图下载。
- 账号收藏保存在云数据库，可在同一账号的不同设备使用。
- 搜同款使用本机图片像素相似检索，返回候选，并非通用语义识别；不上传访客选中的照片。
- 唯一管理员：ChatGPT 登录 + 服务端拥有者邮箱白名单，其他浏览者不能修改。
- 管理员可新建/修改/下架产品、上传主图/长图/视频、调整顺序和地区渠道、管理轮播。
- 文件支持 JPG/PNG/WebP/GIF/MP4/WebM，每个最大 50MB。
- 发布有版本冲突保护；已打开页面每 3 秒拉取最新数据，手机切回页面和窗口重新获得焦点时立即检查更新。网络故障或后台休眠会推迟同步。

## 运行架构

当前 Sites 部署使用平台 D1 数据库与 R2 对象存储。产品信息真实持久化，不使用 localStorage 冒充云同步。

`app/api/catalog` 为资料仓库 API；`app/api/upload` 写入云文件存储；`app/api/media/[key]` 提供媒体和视频 Range 请求。

阿里云接入适配器在 `aliyun-service/`：Node.js 22 HTTP 服务、阿里云 RDS PostgreSQL、OSS V4 浏览器直传。仅在用户配置并部署后启用；交付时不宣称阿里云已连通。

## 本地与 Sites

保留 pnpm 锁文件。安装后执行 `npm run build`；生产 Worker 输出位于 `dist/server/index.js`。
开发运行 `npm run dev`。Sites 环境按 Sites 发布流程部署 `.openai/hosting.json` 对应项目。
数据库结构为 `db/schema.ts`，正式部署会应用 `drizzle/` 的结构迁移。不要将 SQL 迁移放到 API 运行时执行。

本地检查：`node node_modules/typescript/bin/tsc --noEmit`。

管理员入口：网站顶部“管理员入口”或 `/?admin=1`。使用网站拥有者的 ChatGPT 账号登录即可管理。ADMIN_EMAIL 存储于服务端秘密配置，不放进前端。公众浏览权限与管理员写入权限分开控制。

## 阿里云 PostgreSQL + OSS 接入

详见 `ALIYUN_DEPLOY.md`。不需要把 AccessKey 发给浏览器，也不应写入源码或聊天。

## 验收流程

1. 首页搜 CR2016，进入详情，切换主图、下载图片。
2. 收藏后刷新，再在同账号另一台电脑检查收藏。
3. 管理员新建一个测试产品，上传主图、详情、MP4，设置地区渠道，发布。
4. 在另一个设备打开相同站点，3秒内看到更新。
5. 用非管理员账号测试浏览下载，并确认无法调用写入和上传 API。
6. OSS 配置后实测一次签名、PUT 上传、GET 展示、下载；RDS 配置后重启服务确认产品仍存在。

### 本地运行

1. 安装 Node.js 22.13+ 与 pnpm 11.25，执行 `pnpm install --frozen-lockfile`。
2. 在项目根目录执行 `node scripts/restore-local.mjs`，校验素材后恢复本地 D1/R2。默认遇到已有资料会停止；备份后可显式使用 `--replace`。
3. 新建仅本地使用的 `.dev.vars`，内容为 `ADMIN_EMAIL=seedy@sites.test`。不要使用这个邮箱作为生产管理员。
4. 执行 `pnpm dev`，打开终端给出的本机地址。便携开发模式的模拟登录仅允许本机回环访问；生产身份验证由 Sites 提供。
5. 类型检查：`node node_modules/typescript/bin/tsc --noEmit`；接口检查：`node --experimental-vm-modules tests/api-flow.mjs`；构建：`pnpm build`。

不要直接将依赖 Sites 身份头的 Worker 暴露到任意自建反向代理。迁离 Sites 时必须接入真正的身份验证，禁止信任访客自填的身份请求头。工程中的阿里云服务负责数据库和 OSS 适配，不替代身份认证。

管理员删除素材是从产品/轮播移除引用，不会物理清除共享原图，避免误删其他产品正在使用的相同图片。图片内的文字通过替换图片修改。

## 管理员入口密码保护

首页“管理员入口”和 `/?admin=1` 均先显示密码验证页；每次重新打开页面都需输入密码。密码由服务端秘密配置 `ADMIN_ENTRY_PASSWORD` 提供，签名密钥由 `ADMIN_SESSION_SECRET` 提供，源码和浏览器代码不含其值。网站内不提供修改、重置密码功能。服务器/仓库拥有者仍拥有修改部署配置和代码的权限。

验证通过后保留原有唯一管理员 ChatGPT 账号校验；仅知道入口密码不能获取资料编辑权限。保存、上传、OSS 签名及管理员激活接口均检查密码会话。会话使用 HttpOnly、Secure、SameSite=Strict Cookie，一小时到期，可点击“锁定管理员入口”清除。密码验证按网络地址每15分钟最多5次，记录在 D1 `admin_login_attempts` 表（首次使用自动创建）。

部署到其他环境时，须单独安全配置上述两项秘密；GitHub Pages 静态托管无法执行本项目的服务端认证、数据库和上传接口。正式运行入口为 https://shuanglu-visual-center.taofangzhou1231.chatgpt.site 。
