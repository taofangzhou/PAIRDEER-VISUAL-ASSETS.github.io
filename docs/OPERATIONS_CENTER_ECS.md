# 运营中心：ECS 部署与统计口径

运营中心沿用现有管理员登录，统计保存在您自己的 ECS。登录 `https://shuanglu-battery.cn/?admin=1` 后打开「网站运营日志中心」，可查看总览、日期范围明细、热门型号和月份汇总，并导出 CSV 或 XLSX。普通访客无法读取这些报表。

## 更新现有 ECS 网站

在已经运行本网站的 ECS Workbench 执行以下命令。它使用 GitHub 官方 API 下载现有升级脚本，重新获取并构建完整最新源码；现有产品、页脚、分类配置、管理员密码与已发布文件保留。日志位于 `/var/log/pairdeer/`。备份会短暂停止服务，安装会重启；失败时按日志显示的阶段处理。

```bash
curl --fail --show-error --location --retry 3 --connect-timeout 15 --max-time 90 \
  -H 'Accept: application/vnd.github.raw+json' \
  'https://api.github.com/repos/taofangzhou/PAIRDEER-VISUAL-ASSETS.github.io/contents/deploy/upgrade-company-materials.sh?ref=main' \
  -o /tmp/pairdeer-company-upgrade.sh && \
bash -n /tmp/pairdeer-company-upgrade.sh && \
sudo bash /tmp/pairdeer-company-upgrade.sh
```

沿用 Node.js 24、SQLite 和现有 PDF 分页预览工具，不需要新增数据库服务或第三方统计平台。升级脚本会检查匿名访问统计、CSV、XLSX 接口均返回 `403`，不会提交模拟访问、搜索或下载事件。成功后登录原后台查看运营中心即可。

## 五类指标如何计算

| 指标 | 计算口径 |
| --- | --- |
| 访客数（UV） | 从启用统计起，首次出现的匿名浏览器计一次。它不是实名人数；同一人使用不同浏览器、设备或清除 Cookie 后，可能被计为新访客。每日「新增访客」只归入首次出现的日期，不是每天重复计算的日活跃访客。 |
| 页面访问次数 | 打开首页、产品详情、公司 PDF 或公司视频栏目时计数。后台浏览、后台每 3 秒轮询、接口健康检查、预览图片加载与 PDF 翻页不增加页面访问数。 |
| 搜索次数与热门型号 | 用户明确提交非空搜索，包括普通搜索和热门词点击时计数；图片搜索按一次明确提交计数。输入过程、空文本提交不计。热门型号只汇总匹配到的标准产品型号，不保存或展示原始搜索词。一次搜索可以匹配多个型号，排行次数与搜索总次数不必相同。 |
| 文件下载次数 | 已验证文件或素材包后，成功发出下载跳转或 ZIP 响应的请求计数。这表示服务器受理下载，无法证明用户已完整保存到磁盘。ZIP 素材包单独归类，一次 ZIP 请求计一次，不按包内文件数量叠加单文件下载数。 |
| 管理员新增／替换素材数 | 后台成功发布后的新增或替换素材引用计数。仅上传但未发布的草稿不计；系统自动生成的 PDF JPEG 分页图不计为管理员上传。一次发布多个素材引用可以产生多次计数。 |

累计总览从统计启用时开始累计，累计及本月总览卡片不随日期筛选变化。日期筛选默认显示中国时区当月 1 日至今天，单次最多选择 366 天、截至今天；每日明细和热门型号精确使用所选起止日期。

月报展示所选日期覆盖的月份，每行按完整自然月汇总，最多涉及 13 个月。例如选择 11 月 15 日至 12 月 10 日，每日明细只含这些日期，月报仍显示整个 11 月和整个 12 月的累计值；当月数据随真实操作继续增长。界面和导出使用相同的统计口径。

## 日期、月度报表与历史起点

日期统一使用 `Asia/Shanghai`（北京时间），按中国时区午夜划分每天、按自然月划分月份，不依赖浏览器或 ECS 系统时区。每日明细和月份汇总采用同一时区与指标口径。

运营统计从本功能正式部署并收到真实操作后开始积累。部署前的访问、搜索、下载、管理员操作没有相应历史事件，无法可靠恢复；初始数值为零。不根据素材文件数量、修改时间或现有产品数量伪造历史运营数据。没有活动的日期显示零是正常状态。

## 保存范围与导出

运营统计库只保存匿名去重所需的标识值、首次出现日期和汇总计数；不保存、展示或导出 IP、User-Agent、原始搜索词及每个人的浏览行为轨迹。浏览器 Cookie 仅用于匿名去重，不用于建立实名身份。短期事件去重标记不包含个人行为内容。

CSV 与 XLSX 从管理员报表导出，包含统计概览、每日统计、热门型号和月份汇总四部分。每日、热门型号使用选定日期范围，月份汇总按所覆盖的完整自然月计算；不包含访客标识或个人记录。日期输入沿用上述北京时间规则。XLSX 是可直接打开的 Excel 工作簿；导出不需要第三方云端表格或存储服务。

## ECS 数据、备份与升级

产品资料继续保存在 `/var/lib/pairdeer/catalog.sqlite`，运营统计独立保存在 `/var/lib/pairdeer/operations.sqlite`。SQLite 使用 WAL，运行时可能同时出现 `operations.sqlite-wal`、`operations.sqlite-shm`。数据目录随 `DATA_DIR` 配置，标准部署为 `/var/lib/pairdeer`；升级程序不会清空统计。

沿用现有备份命令：

```bash
sudo bash /opt/pairdeer/current/deploy/backup.sh
```

备份脚本暂停应用写入并保存整个数据目录，因此包含产品、媒体、运营数据库及相关 WAL 文件，再恢复服务。恢复时使用一份完整、相互一致的目录备份，不单独替换正在运行中的数据库文件。管理员密码和会话配置仍在 `/etc/pairdeer/pairdeer.env`，请独立私下保管。

运营数据库、WAL 文件、原始备份与管理员凭据均属于 ECS 私有数据，不应提交 GitHub。现有公司素材导出脚本只同步公司 PDF、预览图、视频和公开默认信息，不导出运营库。管理员主动下载的 CSV／XLSX 可自行保管和分享；GitHub 继续用于网站源码和公开素材。
