# 网站运营日志中心（隐私保护型聚合统计）

后台入口：`/?admin=1` → 管理员验证 →「网站运营日志中心」。

## 统计口径

- 累计访问人数：匿名浏览器 Cookie 去重数。服务端只保存使用管理员会话密钥 HMAC 生成的摘要，不保存 Cookie 原值、IP、User-Agent 或身份信息。清除 Cookie、更换浏览器或更换会话密钥后，可能再次计数；因此它是匿名浏览器估算值，不是自然人精确人数。
- 网站累计访问次数、月度访问次数：前台公开页面状态切换时增加页面访问计数；月份按 Asia/Shanghai 统计。后台管理员页面不计入。
- 产品搜索总次数：每次前台提交搜索增加一次。热门型号只对能够与产品目录中型号/产品名称精确匹配的搜索计数；只保存规范化后的型号汇总，不保存原始搜索词或搜索事件。
- 下载次数：按 PDF、视频、图片、详情页/压缩包分类累计。不会保存下载者、文件明细、具体时间线。第三方存储链接按下载按钮点击计数；站内媒体附件按下载请求计数，统计代表下载发起，不保证文件最终完整保存到用户设备。
- 管理员新增/替换素材：根据管理员发布目录前后的素材 URL 差异估算；新增素材与替换素材按同一产品/素材栏位的新增和移除配对计算。单纯调整排序或修改文案不计入素材数。

## 隐私边界

统计数据库只有聚合计数表 `analytics_counters` 和用于匿名浏览器去重的 HMAC 摘要表 `analytics_visitors`。没有用户搜索、浏览、下载明细表；不会记录或向管理员展示原始搜索词、浏览产品清单、下载文件清单、IP 地址或用户行为时间线。热门型号仅显示全站聚合后的型号与次数。

CSV 导出仅导出上述汇总数字，不包含个人行为记录。

## 部署

本功能使用现有 ECS SQLite 数据库，首次调用时自动创建统计表，不需要新增环境变量、RDS 或 OSS。代码合并到 `main` 后，仍须按 `ALIYUN_DEPLOY.md` 的发布流程构建并部署到 ECS；GitHub 源码更新本身不会自动修改正在运行的服务器。历史访问、搜索和下载没有可用的聚合快照，故本功能上线前的历史数值不会回填。
